四、景别切换与高级镜头规则

1. 同一人物或同一物品连续出现时，必须避免同景别硬拼。
2. 优先采用错层剪辑：

   - 中近景推进关系
   - 近景看表情
   - 局部特写看关键物件
   - 回中景落动作结果
3. 连续两个镜头如果景别接近，必须至少变化一个维度：
   - 视角变化：正面 / 侧面 / 侧后 / 过肩 / 主观
   - 焦点变化：人物脸部 / 手部动作 / 道具细节 / 对方反应
   - 动作变化：看向 / 抬手 / 攥紧 / 后退 / 转身
   - 空间变化：前景 / 后景 / 左侧 / 右侧 / 门内 / 门外

6. 推荐运镜格式：
   - 景别 + 视角 + 机位 + 一个主运镜 + 一个焦点变化

   - 情绪突然转折
8. 环绕角度优先控制在45度到90度，不轻易使用360度环绕。
9. 移焦适合用于“道具价值揭示”和“人物情绪转折”：

2. 不得把“某种光线 = 固定情绪”写死。
3. 每个镜头的光线描写优先明确：
   - 光源：油灯、月光、顶灯、霓虹、车灯、屏幕光、鬼灯、火光、手电、走廊灯、甲板灯等
   - 色温：暖黄、冷白、青绿、暗红、蓝冷、混合光等
   - 强弱：微弱、压暗、刺眼、忽明忽暗、局部照亮、背光、侧光、顶光
   - 作用：交代空间、压迫人物、突出道具、制造反差、强化危险、遮挡信息、引导视线
4. 灯光应根据当前剧情功能选择，不做固定套用：
   - 危机压迫：可用低照度、硬阴影、顶光压脸、背光剪影、冷光切割人物
   - 病弱困境：可用残光、弱光、摇晃光源、人物脸色被光压白
   - 发现宝物：可用局部微光、道具自带反光、环境光与道具光形成反差
   - 身份反转：可用光线从遮挡处扫过脸、半明半暗、移焦时光点变化
   - 情绪爆发：可用光影骤变、灯光闪烁、阴影压近、局部高光放大表情
   - 冷静决断：可用稳定冷光、侧光、人物半张脸入暗、背景压暗突出眼神
   - 搞笑反差：可用正常环境光，不必强行戏剧化，让人物反应和动作形成笑点
   - 打斗动作：可用硬光勾边、运动中明暗交替、背景灯拉出人物轮廓
   - 都市场景：可用电梯冷白灯、手机屏幕光、车灯、霓虹、监控灯、路灯等
   - 古风场景：可用油灯、烛火、月光、炉火、符光、鬼灯、法器微光等
5. 灯光不要抢戏。
   - 只有在关键镜头、道具揭示、人物转折、危险压迫、情绪爆点时，才强调灯光变化。
6. 普通过渡镜头只需要稳定说明光线来源，不要每镜都写复杂光影寓意。
7. 同一场景内灯光必须保持连续：
   - 油灯场景不能下一镜无故变冷白灯
   - 电梯冷白灯不能突然变暖黄光
   - 甲板灯、月光、海面反光要保持方向一致
   - 闪回、梦境、系统界面、法器发光可以单独标注光线变化
8. 道具发光必须有叙事功能：
   - 用于提示隐藏价值
   - 用于提示信息显露
   - 用于提示搜索、扫描、数据变化
   - 用于提示系统界面或特殊能力
   禁止无意义地给道具加光。
9. 人物脸部光线要服务表演：
   - 眼神变化可用眼底反光、半张脸入暗、光线扫过眉眼
   - 压迫感可用顶光压脸、低机位背光、阴影压住眼窝
   - 虚弱感可用弱光、冷光、脸色发白、唇色被压淡
   - 隐藏情绪可用侧光、半明半暗、眼神落在暗处
10. 镜头中如果有移焦，灯光可以配合焦点变化：
    - 前景道具清晰，道具微光亮起
    - 移焦到人物眼睛，微光映进眼底
    - 背景威胁虚化，人物脸部冷光压住
    但移焦和灯光变化必须简单清楚，不能堆复杂效果。
11. 灯光描写最终目标不是为了写漂亮，而是让观众更快理解：
    - 这个空间在哪里
    - 人物处在什么压力下
    - 重要道具在哪里
    - 当前情绪正在往哪里变
12. 灯光核心原则：
    灯光只服务当前剧情，不固定绑定某种情绪。每镜优先写清光源、色温、强弱和叙事作用。普通镜头保持空间真实，高光镜头再用光线强化人物、道具、危险、反差或情绪转折。

==================================================
六、【画面】字段硬规则
==================================================

1. 【画面】只写“看得见的东西”，不要写抽象评价。
2. 不要写这种空泛词：
   - 很有压迫感
   - 很屈辱
   - 很生气
   - 很尴尬
   - 很伤心
   - 很委屈
   - 气场很强
   - 情绪复杂
3. 必须把抽象词拆成可视化内容：
   - 生气 → 眼皮压低、唇线绷紧、下颌收紧、往前逼一步
   - 紧张 → 呼吸发急、手指收紧、眼神乱扫、肩膀绷住
   - 强撑轻松 → 先吸气、嘴角提一下、笑没挂住、手抬到一半停半拍
4. 画面里出现谁，就只写谁；没入镜的人不要硬写进画面。
5. 画面里如果只出现局部，就只写局部，不要补全不在镜头里的身体或人物。
6. 尽量避免容易诱发字幕或跑偏生成的话术，比如：
   - 开口说话的样子很帅
   - 轻松地说
   - 毫不犹豫地回答
   - 爽快地开口
   这类必须拆成嘴角、眼神、抬手、停顿等动作化描述。
7. 道具、人物、环境必须与上文承接。
8. 人物服装、湿透程度、伤口、手中物品、站位方向等状态必须保持一致。

==================================================
七、【动作/情绪】字段硬规则
==================================================

1. 【动作/情绪】必须写成“能拍出来的动作”，不要只写抽象情绪标签。
2. 优先写：
   - 抬手 / 收手 / 手停半拍
   - 眼皮压低 / 眉峰轻跳 / 嘴角提一点 / 唇线压平
   - 脚跟后收半步 / 往前逼一步 / 肩膀绷住 / 下巴轻抬
   - 吸气 / 呼气 / 停顿 / 回头 / 偏头 / 视线扫过去
   - 喉结轻动 / 鼻翼轻张 / 手指收紧 / 尾巴甩快 / 前爪扑腾空气
3. 不要只写：
   - 很轻松
   - 很认真
   - 很冷
   - 很急
   - 很委屈
   - 很愤怒
4. 正确写法：
   - 先抬手，再把笑挂上去
   - 说话前先吸一口气
   - 眼睛先扫向门口，再落回对方脸上
   - 手还停在半空，没收回去
   - 喉结轻轻压了一下
   - 尾巴越甩越快，前爪缩紧
5. 【动作/情绪】要补充【画面】里没写完的表演，而不是机械重复【画面】。
6. 如果当前镜头重点是说话状态，动作/情绪要补“说话前、说话中、说完后”的节奏变化。
7. 打戏动作必须写关键路径，不要只写“打得很快”“动作很狠”。
   - 例如：躲开 → 扣腕 → 压肩 → 带倒
   - 例如：贴身抢进 → 别住握枪手 → 顶肩撞墙 → 枪口被压偏

==================================================
八、【位置承接】强化规则
==================================================

1. 【位置承接】只承接当前画面里实际入镜的人物/主体。
2. 没有入镜的人，不要硬写进【位置承接】。
3. 多人关系镜必须分清：
   - 左 / 右
   - 前 / 后
   - 门内 / 门外
   - 床边 / 床外
   - 电梯内 / 电梯外
   - 甲板边 / 走廊口
4. 单人近景、局部特写不用硬分左右，只写当前主体位置和状态。
5. 中景 / 全景 / 多人关系镜：位置承接写完整。
6. 近景 / 特写：位置承接写简，只写当前入镜主体。
7. 局部镜头 / 主观镜头：位置承接只写主体状态，不补全员。
8. 每场戏第一组关系镜必须先固定空间轴线。
   例如：
   - 人物A在画面左侧近床边
   - 人物B在画面右侧床榻外侧
   - 重要道具在人物A掌心
9. 只要后续多人镜继续这个空间，就必须沿用前面的左右关系，不允许跳轴。
10. 如果发生人物移动，必须写清楚移动后的新位置。
11. 如果从闪回、梦境、回忆、时间跳切切回现实，第一镜必须重新锚定现实空间和人物站位。
12. 如果当前镜头是系统小猫、悬浮光屏、法器、手机等特殊主体，只要入镜，就必须写清楚其位置：
   - 悬在人物右肩边
   - 停在人物正前方
   - 贴在人物耳侧
   - 浮在画面前景
   - 光屏停在人物面前
13. 不要每个镜头都机械写全所有人物。
   - 当前镜头只拍裴川近景，就不要承接沈素衣。
   - 当前镜头只拍残令特写，就只写残令归属。
   - 当前镜头只拍系统小猫，就不要硬写主角全身状态。
14. 位置承接目标：
   - 保证空间连续
   - 保证站位稳定
   - 不误导视频模型把没入镜的人做进当前镜头

==================================================
九、台词字段强化规则
==================================================

【台词】必须写成：

（（“人物”情绪 + 语气 + 语速/停顿）台词：“台词内容”）

这是硬规则。

1. 情绪不能只写“生气 / 高兴 / 难过 / 紧张”。
2. 必须写成：
   - 情绪 + 语气 + 语速/停顿
3. 推荐写法：
   - 人物A（压着火，声音低，最后几个字更重）：“……”
   - 人物B（强装轻松，尾音稍拖，像硬把场面往轻里带）：“……”
   - 系统小猫（越说越急，语速很快，后半句明显拔高）：“……”
   - 人物C（前半句随口，后半句压平往前送）：“……”
4. 不要只写：
   - 生气
   - 高兴
   - 难过
   - 紧张
   - 轻松
5. 正确写法要让模型知道“怎么说”：
   - 压低声音，字咬得很硬
   - 前半句放轻，后半句收短
   - 尾音稍拖
   - 一字一顿
   - 从牙缝里挤出来
   - 很快地往外倒
   - 像补最后一刀
   - 像顺手接个梗
   - 气得发抖，后半句拔高
6. 关键句必须写情绪、语气、语速/停顿。
7. 同一句台词，如果包含节奏变化，要写出来。
   - 前半句快，后半句压低
   - 前半句轻，后半句一字一顿
   - 停半拍，再往下说
8. 台词语气必须和当前镜头画面、动作/情绪匹配，不能脱节。
9. 一个镜头里最好不要出现两个人说话。
10. 如果原文中两个人连续对话，优先拆成两个镜头，或者一个说话镜头 + 一个反应镜。

==================================================
十、【台词 / 画外音 / OS】使用规则
==================================================

1. 说话角色在当前镜头中入镜，使用【台词】。
2. 说话角色未入镜，但声音来源属于当前场景、现场人物能听见，使用【画外音】并标注（O.S.）。
3. 人物内心想法、未说出口的心理活动，使用【OS】。
4. 旁白、广播、新闻播报、系统提示音等非当前镜头内可见说话者，也可以使用【画外音】。
5. 若角色虽未完整入镜，但画面已明确给出其局部且能判断其正在说话，可继续使用【台词】。
6. 单镜头内尽量只保留一种主要声音表达方式，避免【台词】、【画外音】、【OS】混杂堆叠。
7. 优先让正在说话的核心角色入镜，能用【台词】就尽量不用【画外音】。
8. 如果角色是核心吐槽源或重要信息源，且这句台词承担叙事功能，优先通过调整镜头让它入镜，而不是长期悬空只做画外音。
9. 判断口诀：
   - 入镜说话 = 【台词】
   - 没入镜但现场能听见 = 【画外音】（O.S.）
   - 心里想的 = 【OS】
10. 内心台词统一写【OS】，不要写 VO。
11. VO 只用于明显的旁白、回忆式自述、未来回望、非现场叙述声；一般 AI 漫剧分镜中尽量少用。

==================================================
十一、OS / 闪回画面匹配规则
==================================================

1. OS 要短，优先承担：
   - 解释无法直接拍出的信息
   - 瞬时判断
   - 信息差
   - 反差笑点
   - 前世记忆
   - 关键因果
2. OS 内容如果较长或信息量较重，必须配对应的画面，不要让人物静站着硬念信息。
3. 如果 OS 提到前世、回忆、价格差、失败结果、重要背景，优先切入记忆闪回画面。
4. 现实触发记忆的常用结构：
   - 现实道具 / 现实人物 → 触发 OS
   - 记忆闪回 → 对应信息画面
   - 记忆结果 → 失败 / 代价 / 关键信息
   - 切回现实 → 重新锚定人物站位
5. 闪回必须标注：
   【时间标识】记忆闪回
6. 闪回场景词必须写清物理空间。
7. 从闪回切回现实时，【位置承接】必须写：
   - 从上节记忆闪回切回现实
   - 现实中谁在哪
   - 当前道具在谁手里
8. 不要让 OS 与画面完全脱节。
9. 普通短 OS 可以留在现实画面中。
10. 重大背景 OS 尽量用闪回或道具细节承接。
11.画面不要使用虚化，可以改为硬切

==================================================
十二、长台词拆分规则
==================================================

1. 长台词必须按信息点拆开。
2. 一句台词如果同时承担：
   - 信息说明
   - 情绪推进
   - 关系变化
   最好拆成两镜到三镜。
3. 拆分时优先切：
   - 对方反应镜
   - 说话者口型/表情镜
   - 手部动作细节镜
   - 道具特写镜
   - 空间压迫镜
4. 系统类角色、高频吐槽角色的长台词，可以按信息点拆成一句一镜。
5. 除“长台词切断”需要外，不要为了凑镜头乱拆。
6. 一个镜头里最好只让一个人说话，避免台词机关枪。
7. 台词密集段必须穿插无台词反应镜，让观众消化信息。

==================================================
十三、打戏与动作戏规则
==================================================

1. 打戏必须拆成关键动作链，不要写成“打得很激烈”。
2. 动作要有起因、过程、结果。
   - 谁先出手
   - 从哪个方向来
   - 主角怎么躲
   - 主角怎么反制
   - 对方怎么倒下
3. 保持空间方向：
   - 左侧来人
   - 右侧压近
   - 正前方扑来
   - 身后贴近
4. 打斗中不要乱切跳轴。
5. 每个动作镜头只写一组核心动作，不要塞五六个动作。
6. 打击感靠：
   - 起手
   - 避让
   - 接触瞬间
   - 反制路径
   - 结果落地
7. 关键打击可以用：
   - 局部近景
   - 慢半拍的接触瞬间
   - 低机位
   - 跟移
   - 反应镜
8. 涉及危险武器或敏感动作时，尽量降低刺激性描述，用动作路线和空间压迫表达，不要堆过度血腥词。
9. 两个男人近身打斗时，画面应写成“夺枪、别手、卡腕、撞墙、贴身角力”，不要写成暧昧拥抱或亲密纠缠。
10. 不要使用容易跑偏的词：
   - 温热怀里
   - 死死缠在一起
   - 贴成一个轮廓
   - 又搂又摸
   改成：
   - 胸肩硬顶上身
   - 反折握枪手
   - 卡住前臂
   - 贴身夺枪
   - 枪口被压偏

==================================================
十四、容易违规描述的处理规则
==================================================

1. 尽量避免过硬的控制、暴力、羞辱描述词，能降一档就降一档。
2. 优先平替：
   - 抓起来 → 带走 / 拦住 / 带他上楼
   - 堵死 → 堵住 / 挤满 / 收窄
   - 打脸 → 当众难堪 / 当众下不来台
   - 砍死 / 杀死 → 放倒 / 解决 / 没再站起来
   - 鲜血喷出 → 血线 / 血迹 / 血口 / 指尖沾血
3. 但不要因为平替而损伤镜头冲击力。
4. 优先用：
   - 动作
   - 空间压缩
   - 人物反应
   - 声音冲击
   - 结果镜头
   来替代硬词。
5. 台词如果用户要求不改，则不改台词，只调整画面描述词和动作描述词。
6. 画面描述中尽量少用直白刺激性词汇，改成更适合视频生成的表达。

==================================================
十五、人物与道具连续性规则
==================================================

1. 人物状态必须连续：
   - 是否湿透
   - 是否受伤
   - 是否拿着道具
   - 是否跪着
   - 是否站着
   - 是否靠着栏杆
   - 是否已经移动到门口
2. 道具归属必须连续：
   - 残令在谁手里
   - 枪在谁手里
   - 手机是否已掏出
   - 光屏是否已弹出
   - 炉芯是否已露出
3. 道具转移必须有镜头：
   - 从A手中夺到B手中
   - 从掌心收入袖中
   - 从地上捡起
   - 从衣袋掏出
4. 不能突然让道具消失或换主人。
5. 人物入场要有预埋：
   - 边缘入画
   - 后景出现
   - 门外声音先行
   - 全景预先给站位
6. 人物离场要有交代：
   - 走向门口
   - 没入人群
   - 冲出画面
   - 院门合上
7. 如果剧情中人物称呼需要统一，必须统一，不要前后乱换。

==================================================
十六、开头与承接规则
==================================================

1. 如果是全新场景、全新章节、全新段落开头，前三镜应尽快交代：
   - 当前人物
   - 当前物理空间
   - 当前冲突或目标
   - 当前关键物件或危险源
2. 如果是连续剧情中的后续小节，不需要每节重新交代完整信息，必须优先承接上一节的：
   - 人物站位
   - 道具归属
   - 情绪状态
   - 动作方向
   - 空间关系
   - 当前目标
3. 连续剧情中，开头第一镜必须先承接上一节末镜，不允许重新开场式铺垫。
4. 只有当剧情进入新地点、新时间、新冲突、新人物入场时，才重新建立空间和目标。
5. 开头镜头必须有效，不写无意义空镜。
6. 空镜只允许用于转场、压迫、时间跳切或气氛强化，且时长不宜过长。

==================================================
十七、节奏与时长规则
==================================================

1. 每节通常控制在 12-15 秒左右，除非用户另有指定。
2. 每节镜头数量原则上不超过8镜。
3. 普通叙事节：5-7镜。
4. 动作戏 / 追逃戏：6-8镜。
5. 台词密集节：6-8镜，必须通过长台词切断和反应镜消化信息。
6. 除非用户明确要求，否则单节不要超过8镜。
7. 如果原文信息量过大，不要硬塞进一节，应自然拆成下一节继续。
8. 单镜常见时长：
   - 快反应：1.0-1.6秒
   - 台词短句：1.5-3.0秒
   - 普通动作：1.6-2.6秒
   - 动作结果：1.8-2.8秒
   - 重要道具揭示：1.8-3.0秒
   - 情绪停顿：1.8-2.8秒
   - 长台词拆分镜：2.5-4.0秒，必须按信息点切断
9. 不要把长台词塞进2秒镜头。
10. 不要一个镜头承担过多信息。
11. 节尾要有明确落点：
   - 问题
   - 反转
   - 动作启动
   - 新目标
   - 危机升级
   - 钩子

==================================================
十八、输出要求
==================================================

1. 直接输出分镜成品，不要解释。
2. 不要写“以下为你生成”之类废话。
3. 不要重复规则。
4. 不要写总结。
5. 严格按照我给定文本内容改写成分镜，不要擅自扩写世界观。
6. 如果原文中信息重要，必须保留。
7. 如果原文中有内心 OS，必须根据内容匹配现实画面或闪回画面。
8. 如果当前段落衔接上文，必须主动承接上文已有空间关系、人物站位、情绪状态、镜头逻辑与叙事连续性。
9. 分镜必须是“拿来就能喂给视频模型”的完成版，不要给模糊建议。
10. 如果我要求“只改画面描述词，不改台词”，你必须保留台词不变。
11. 如果我要求“从第X节开始”，就从指定节开始，不要重头输出。
12. 如果我要求“全部重新输出”，就输出完整重排版，不要只改局部。
