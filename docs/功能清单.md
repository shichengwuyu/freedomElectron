# Freedom 功能清单

> 小说 → 剧本 → 分镜 → 元素 → 出图 → 视频，一站式短剧流水线（Windows 桌面应用）
>
> Electron 外壳 + 本地 Node 服务；前端零构建（Vue 3 + Element Plus）。数据全部保存在本机。

---

## 一、项目控制台

应用的首页，所有项目的入口。

- **新建项目**：填名字 → 开拍；也可**导入项目包**（`.zip`）
- **一键生成**（全自动流水线）：粘贴/上传小说 TXT，从零跑到成片
  - 新建项目 或 续跑已有项目（已有产出自动跳过）
  - 可选：全局画风、每集目标时长（自动换算镜头数）、剧本/分镜并行数（1–5）、要出图的元素类型
  - 开跑前给出**成本预估**；运行中显示阶段进度、实时日志、失败项，可停止/后台运行
  - 成片自动导出到 `下载/Freedom成片/<项目名>/`
- **项目分区**：活跃 / 已归档 / 回收站（回收站可恢复、可永久删除、可清空）
- **列表工具**：搜索（名称/ID/描述）、排序（最近更新 / 最近打开 / 名称 / 创建时间）、**批量导出**（多选项目打包）
- **项目卡片**显示：封面、名称、描述、剧集数、分镜数、人物数、资产数、占用空间、更新时间
- **卡片快捷操作**：重命名、复制项目、导出项目包、**版本历史**（快照列表，可恢复到某一版）、归档/取消归档、移入回收站
- **整库备份 / 恢复整库**（整个数据目录打包与还原）

## 二、小说工坊（写小说）

从想法到成书。

- **书架**：卡片墙展示所有作品（封面、题材、男频/女频、目标字数、章节进度、已写字数），支持搜索
- **创作新作品**：进入 AI 创作对话，逐步把设定问出来
- **写作台**（两个模式）
  - **对话**：AI 创作助手，支持会话列表、消息队列（排队串行执行）、快捷指令、**联网搜索**开关、Skill 路由；AI 会给出提取字段、创作诊断、创作简报、可选项，并**真正执行动作**
  - **正文**：章节编辑器，逐章写作
- **右侧面板（8 个页签）**：
  - **目录**：章节列表与进度
  - **蓝图**：故事蓝图（可编辑）
  - **人物**：人物档案（可编辑）
  - **记忆**：长期记忆
  - **伏笔**：伏笔台帐（可编辑）
  - **Radar**：节奏/看点雷达
  - **质检**：质量分与问题清单，可重新检查
  - **轨迹**：每次生成的写作模式（单写手 / 多稿竞选）、入选稿、流水线各阶段状态
- **生成封面**：内嵌封面生成器（本地素材 / 素材图库两种来源）
- **市场**：榜单 / 学习 / 打包（题材参考）
- **复制全文**

## 三、工作台（项目内）

项目里的主战场，两个阶段：**剧本** → **分镜**。

顶部是流水线导航：原文（字数）→ 剧本（集数）→ 分镜（份数）。

### 剧本阶段
- **剧本生成设置**：改编强度（忠实改编 / 短剧强化 / 二创重构）、分段质量审稿、完整单集终审、首集冷开场、单集追看钩子、精准提纯、长剧本、内容审核
- **逐集生成 / 重生成**（改了原文会提示"原文已改·重生成"）
- **专注模式**（隐藏原文对照，居中沉浸写剧本）
- **导出本集剧本**、**导入剧本**
- 单集 / 全部集批量生成与进度显示

### 分镜阶段
- **生成分镜 / 重生成分镜**、**导入分镜**（可用自己的分镜文本）
- **一键生成本集视频**、**一键全集串行**（按章节顺序逐集自动生成分镜，可同时逐镜首尾帧串联生成视频）
- **一键首尾帧**（尾帧承接下一镜）
- **绑定总览**：按镜头列出元素绑定状态，标出待查项
- **场景补建**：扫描分镜里的场景标记，找出元素库缺失的场景并一键补建
- **视频队列工具**：一键重新抓取上游视频、一键强制移除跟踪
- **镜头管理**（时间轴面板）：拖拽排序、Ctrl 多选、Shift 连选、Alt+方向键移动、**L 键锁定**、批量锁定/筛选（全部 / 缺视频 / 需关注）
- **片头**：项目级共用开场片段，导入后可替换/删除；排在镜头 1 之前，**不参与分镜编号与承接连续性**
- **镜头卡片**：镜头号、画面提示词、景别/运镜、时长、情绪、旁白、台词、音效、元素标签绑定（`@` 提及）、逐镜生成图/视频、锁定、隐藏提示词、单独重生成
- **导出与工具**
  - 导出本集分镜 TXT
  - 导出**范围合并**分镜 TXT（按「起始集 — 结束集」）
  - 导出卡片分镜
  - **导出到剪映**（生成剪映草稿）
  - **导出成片**到 `下载/Freedom成片/<项目名>/`（可限定集数范围）

### 元素与资产
- **选角与资产工坊**（元素库抽屉）：分类为人物 / 群像 / 场景 / 道具 / 特效 / 妖兽
  - 元素提取（从原文按章节提取，可增量）
  - 元素出图 / 批量出图
  - 单个元素的名称、描述、提示词、参考图、多套造型（变体/服装）、角色语音
  - **造型管理**（wardrobe）：多套造型的生成、切换主图、删除
- **全局素材图库**：跨项目浏览已生成图片，搜索/按项目/按分类筛选，批量加入当前项目，或作为某个元素的图直接选用

### 质检与成本
- **项目质检**：跑一遍项目数据，给出评分与问题清单（可修复的提供一键修复入口）
- 工具栏实时显示：镜头数、已成片时长、待处理数量

## 四、画布

独立的无限画布创作空间（与项目互不影响）。

- **画布项目库**：卡片墙，显示节点数 / 素材数 / 存储占用 / 更新时间；可复制、删除、打开素材文件夹
- **无限画布编辑器**：拖拽平移、滚轮缩放、框选、小地图、适应全部内容、清空画布
- **节点类型**：灵感便签、AI 推理卡、图片、视频、音频、创作分区
  - 快捷键：`N` 便签 / `T` 推理 / `I` 图片 / `V` 视频 / `A` 音频
  - 节点内可直接**生成**（选渠道与模型）、导入本地媒体、抽帧、引用其他节点（`@` 提及）、连接成流程
- **连线**：拖拽连接、断开
- **右侧停靠面板**：素材库（当前画布 / 全部，按图片/视频/音频筛选、可拖到画布）、时间轴（播放、刻度、拖动定位）、历史记录（撤销 / 重做 / 恢复到某一步）
- **画布 Agent**：用自然语言指挥画布，直接增删节点、连线、改内容

## 五、封面生成

独立工作区，专做小说封面。

- 输入：封面标题（可写入画面艺术字）、故事想法/简介
- 题材：内置题材一键选择，也可自定义
- 画面比例：9 种（1:1 / 2:3 / 3:4 / 4:5 / 9:16 / 4:3 / 3:2 / 16:9 / 21:9）
- 本地参考图：最多 9 张（可拖入），每张可指定参考类型
- 生成后可**下载 PNG**；**历史生成**支持预览、下载、删除、清空

---

## 六、一键切割

本地视频工具，把长视频按规则切成多集。

- **视频来源**：一次可选多个文件，**合拍顺序**可上移/下移/移除
- **切割规则**：按「第 X 集 至 第 Y 集」设定每段时长（分钟/秒），可加多条规则；未覆盖的集数默认 40 秒
- **最低时长**：结尾不足时并入上一集，不跳过任何内容
- **自然切割**：目标时间还在说话时，自动往后找停顿再切，可设最多顺延秒数
- **输出设置**：文件名前缀（带命名预览）、输出文件夹
- 结果列表显示每一集的时长与起止时间；原视频不会被修改

## 七、任务中心

- 状态筛选：全部 / 执行中 / 等待中 / 已暂停 / 失败 / 已取消 / 已完成
- 任务行：标题、状态、时间、详情、进度条、来源/渠道/项目/集数/镜头等元信息
- 操作：**定位**（跳到对应的剧本/分镜/镜头）、取消、重试、移除
- **清理已结束**、刷新
- 任务**持久保存**：应用重启后未完成任务进入暂停态，可随时重试；执行中的任务数量在侧边栏有实时提示点

## 八、聊天

本地化的通用 AI 对话（数据落本机 SQLite）。

- 会话管理：对话 / 归档 / 回收站，文件夹分组，置顶、重命名、归档、删除、恢复
- 搜索：全局搜索 + 对话内搜索（可跳转匹配）
- 模型选择、**上下文占用**显示、上下文自动压缩 / 清空
- 对话设置：提示词预设、Skill 启用与导入、**图片模式**（比例、并发）、**双模型对比**回答、回答风格（完整/简洁/平衡/详细）、温度
- 消息操作：引用、收藏、评分、**重新生成**、自动续写、**版本切换**、**回答分支**
- 附件上传、临时对话（关闭应用即删）

## 九、Agent 全权控制台

用一句中文指挥整个项目。**先说它**会**执行什么，确认后才动手**。

- 输入指令 → **生成计划** → 弹出动作清单（每条翻译成中文，危险动作用橙色标出「改写数据 / 消耗额度」）→ **确认执行** / 取消
- 能做的事（4 类）：
  - **改内容**：章节、分镜镜头、元素（人物/场景/道具/特效）的增删改
  - **跑生成**：单集或全部剧本/分镜、出图与批量出图、单个或全部镜头视频、整条流水线
  - **填素材**：把附件图片直接写进元素图 / 参考图 / 角色造型 / 服装 / 角色语音
  - **改配置**：直接改写项目与设置里的字段，并调用本地接口
- **附件**：图片/音频/视频/文本，最多 12 个、合计 50 MB
- **小说原文 → 全流程**：传一本 TXT，一键跑完整条流水线（可选提交视频）
- 右侧常驻：项目上下文、**动作日志**（每一步干了什么）、进度条

## 十、设置

左侧 12 个分区：

| 分区 | 主要内容 |
|---|---|
| **主题外观** | 深色 / 浅色 / 跟随系统；界面缩放 85%–150% |
| **文本模型与路由** | 文本模型（Base URL / API Key / 模型 / 温度 / 最大 tokens、备用端点与故障切换）；**多模型路由**（按任务指定主模型与备用模型、自动降级、重试次数） |
| **图片模型** | 生图渠道：LibTV CLI / 即梦 CLI / UpDream / Neo / 通用 API；通用 API 支持多渠道（列表 + 抽屉编辑、主渠道、自动切换备用、单渠道重试） |
| **图床** | 关闭 / 免费图床 / 自定义 / 阿里云 OSS / 腾讯云 COS / Cloudflare R2 / AWS S3 |
| **视频模型** | 小云雀 / 即梦 CLI / 即梦 Agent / LibTV CLI / UpDream / Neowow / ComfyUI H3 / 视频 API；各渠道账号管理、比例/清晰度/时长/价格 |
| **模型网关** | 统一网关地址（new-api，OpenAI 兼容），填自己的地址同样兼容。卡密购买 / 兑换入口**只在配置了 `gateway.shopUrl` 时显示**（开源发行版默认不显示任何购买入口） |
| **成本中心** | 估算总成本、Tokens、图片张数、视频秒数、失败数；月度预算与超支提醒；按模型/任务汇总与最近调用记录 |
| **生成防误发** | 视频生成前倒计时确认（可设 1–120 秒），发现分镜或参数有误可取消 |
| **提示词设置** | 各画风（仿真人 / 2D / 3D）的整体风格描述；元素提示词分类自定义 |
| **提示词库** | 剧本 / 分镜提示词的新增、导入、编辑、删除，设为当前项目使用或切回内置 |
| **提取设置** | 元素提取逻辑（两套提示词）、分块大小、提取并发数 |
| **系统与诊断** | 软件更新（检查/下载/重启更新）、**数据存储位置**（选择目录 / 打开 / 恢复默认）、硬件加速、减少动画、低配流畅模式、运行诊断（刷新状态 / **导出脱敏诊断包**） |

## 十一、跨模块能力

- **全局快速跳转**：`Ctrl + K` 命令面板（切页面、跳阶段、跳集/分镜、打开项目、打开 Agent）
- **主题**：深色 / 浅色 / 跟随系统（侧边栏底部一键切换）
- **界面缩放**：85%–150%
- **通知**：任务完成桌面通知
- **软件更新**：应用内检查 / 下载 / 重启安装
- **诊断**：运行状态与脱敏诊断包导出
- **数据位置**：默认在安装目录同级 `Freedom-Data`，可用 `GG_STORAGE_ROOT` 自定义；卸载默认保留用户数据
- **账号授权**：注册 + 登录（设备绑定、租约有效期、离线宽限）
- **使用条款**：首次启动需阅读并同意

## 十二、支持的模型渠道（一览）

| 类型 | 渠道 |
|---|---|
| 文本 | 任意 OpenAI 兼容接口（含备用端点 + 多模型路由/降级） |
| 图片 | LibTV CLI、即梦 CLI、UpDream、Neo、通用图片 API（多渠道） |
| 视频 | 小云雀、即梦 CLI、即梦 Agent（官网登录态）、LibTV CLI、UpDream、Neowow（多账号）、ComfyUI H3、视频 API（多渠道） |
| 图床 | 免费图床（Litterbox / Uguu / ImgBB）、自定义、阿里云 OSS、腾讯云 COS、Cloudflare R2、AWS S3 |
