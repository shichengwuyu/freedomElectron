# 《漫剧 AI 创作 SaaS 平台》全栈架构与实现细节

> 基于 Cloudflare Workers 边缘计算的漫剧 AI 创作 SaaS 平台：小说 → 剧本 → 分镜 → 角色元素 → 图像 → 视频，全流程自动化生成。

---

## 0.1 这套文档是什么

这是一份**架构设计 + 实现细节**双线并行的技术文档：

- **架构线**：讲清楚每个模块"为什么这么设计"，包括技术选型论证、备选方案对比、架构权衡（trade-off）；
- **实现线**：讲清楚"具体怎么落地"，包括核心数据结构（TypeScript 定义）、关键算法（贝塞尔曲线、环检测、防抖同步）、异常路径（冲突、失败、超限）的处理。

每一章末尾附**面试考点提炼**，标注面试官最可能深挖的点。

## 0.2 写作口径声明

文档以项目描述（简历口径）为纲展开。其中具体参数（防抖时长、步数上限、内存阈值等）采用"业界常见 + 逻辑自洽"的参考值编写，用于说明设计方法；如果与真实代码有出入，**以你的真实实现为准进行替换**——面试时说出自己真实的数字和踩坑故事，远比背标准答案有说服力。

## 0.4 面试速读路线

只有 30 分钟准备时间时，按这个顺序读：

1. `01-总体架构.md` 的 1.2（架构图）+ 1.3（选型论证）——回答"介绍一下项目"和"为什么这么选型"；
2. `04-状态管理与持久化.md` 的 4.3~4.5（三层数据持久化）——简历最靠前的自研亮点；
3. `06-AI-Agent系统.md` 的 6.2（ReAct 循环）+ 6.4（上下文管理）——AI 岗位必问；
4. `08-视频合成系统.md` 的 8.3（内存分段）——最有故事性的难点素材；
5. 每章末尾的"面试考点提炼"扫一遍。

## 0.5 术语表

| 术语 | 含义 |
|---|---|
| 画布（Canvas） | 用户进行节点编排的 2D 无限平面工作区 |
| 节点（Node） | 画布上的功能单元，8 种类型之一 |
| 连线（Edge） | 节点端口之间的有向数据通道 |
| 端口（Port） | 节点边缘的连接点，分输入/输出，携带数据类型 |
| 导演台（Director） | 3D 场景预览与镜头编排模块 |
| Agent | 由 LLM 驱动、可多步调用工具的智能助手 |
| Tool Calling | LLM 以结构化参数调用预定义工具的机制 |
| 流水线（Pipeline） | ffmpeg.wasm 视频合成的五阶段处理链 |
| RLS | PostgreSQL 行级安全（Row Level Security） |
| OPFS | 浏览器源私有文件系统（Origin Private File System） |
