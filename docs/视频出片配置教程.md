# Freedom 分镜出片配置教程（图床 / 视频渠道 / 排错）

> 适用：Freedom 桌面版。分镜「生成视频」报错时，90% 是**图床**或**视频渠道凭证**没配好。
> 本文按「先对号入座 → 最少步骤跑通 → 详细配置 → 排错」组织，全部是「点哪个菜单、填哪个字段」。

---

## 0. 四个常见报错，先对号入座

| 报错原文（任务面板 / 分镜上） | 真实原因 | 看哪节 |
|---|---|---|
| `{"error":"\"image_urls\" must be a public http(s) URL"}` | 上游只收**公网图片链接**，你的参考图是以 base64 / 本地路径发出去的（图床没开或没配好） | §2 |
| `{"error":"\"video_urls\" ..."}` / `"audio_urls" ...` | 同上，参考视频 / 参考音频不是公网链接 | §2 |
| `invalid image input: private IP address not allowed: 127.0.0.1` | 参考图给的是本机 / 内网地址（如 `http://127.0.0.1:...`） | §2 |
| `UpDream Access Token is not configured` | 视频渠道选了 **UpDream** 但没填 Token | §4 |

补充两条也属于「渠道没配好」，现在会在**提交前**直接给中文提示，不会白跑一次上游花冤枉钱：

- `UpDream 未配置 Token：请到“设置 → 视频 → UpDream”填写 Access Token（或 Refresh Token）后重试`
- `Neowow / 小云雀 / LibTV / ComfyUI 未配置…`

---

## 1. 五分钟跑通（最少步骤）

1. 打开 Freedom，进「**设置**」。
2. 「**模型网关 & 卡密**」：填网关地址 / 令牌，或用卡密充值。
3. 「**图床**」→「图床类型」选 **免费图床** → 「免费图床」选 **自动选择** →
   点右上角「**测试上传**」，出现绿色 `可用 · 直链正常` 就算配好。
4. 「**视频模型**」→「默认视频渠道」选 **视频 API** →
   填 `Base URL`（默认 `https://api.xiaoyxiao.xyz/v1`）、`API Key`、模型名（默认 `seedance-2.0-mini-deal`）。
5. 回项目 → **分镜** → 选中镜头 → 生成视频。

> 只做这 5 步，参考图能上传、网关能建单，出片链路就是通的。

## 2. 为什么必须配图床

视频上游（喵呜 / 极途等）的服务器是**自己去抓参考素材**的，所以它只接受**公网 http(s) 链接**。客户端把本地图片转成公网链接的唯一办法就是「图床」。

直连网关实测（模型 `seedance-2.0-mini-deal`）：

| 发的素材 | 上游结果 |
|---|---|
| base64 内联（`data:image/png;base64,...`） | ❌ `"image_urls" must be a public http(s) URL` |
| 本地文件路径（`F:\...\a.png`） | ❌ 同上 |
| `http://127.0.0.1:8848/a.png` | ❌ `private IP address not allowed` |
| 图床产出的公网链接 | ✅ `200 queued` |

所以：**只要视频渠道是「视频 API（内置网关）」或「飞拓跨界」，图床就是必需品**，不是可选项。

> 新版客户端做了兜底：如果图床设成了「关闭」，打这两类渠道时会**自动临时改用免费图床**，并提示「图床未启用…已自动改用『免费图床』」。但仍建议按 §3 正式配好，尤其是要长期稳定用的时候。

## 3. 图床怎么选、怎么填

进「**设置 → 图床**」，先选「图床类型」，再填对应字段，最后点「**测试上传**」。

### 方案 A：免费图床（推荐给没有云存储的人，开箱默认）

- 「图床类型」= **免费图床**
- 「免费图床」= **自动选择**（依次尝试 ImgBB → Litterbox → Uguu）

| 子选项 | 特点 |
|---|---|
| 自动选择 | 优先 ImgBB（填了 Key 才试），再 Litterbox，再 Uguu |
| Litterbox | 上传快、国内实测可通；**有有效期**（1/12/24/72 小时，在「图片有效期」里选） |
| Uguu | 有效期 3 小时 |
| ImgBB | 需要自己去 imgbb.com 免费申请 API Key，填进「ImgBB API Key」 |

注意：

- 这是**第三方公共图床**，参考图会上传到别人家服务器，**别传私密/敏感素材**。
- 都在境外，国内偶发连不上；上传失败会明确报错（如 `免费图床均不可用：…`）。
- 参考图只在「提交那一刻」被上游抓走，24 小时有效期足够；重新生成会重新上传，不受过期影响。

### 方案 B：自己的云存储（有腾讯云 COS / 阿里云 OSS / R2 / S3 的人）

以**腾讯云 COS** 为例（「图床类型」= **腾讯云 COS**）：

| 字段 | 填什么 | 例子 |
|---|---|---|
| Bucket | `存储桶名-APPID` | `mybucket-1315399269` |
| Region | 存储桶地域 | `ap-guangzhou` |
| Access Key ID | 腾讯云 AK | `AKIDxxxxxxxx` |
| Secret Access Key | 腾讯云 SK | `xxxxxxxx` |
| 公开访问域名（可选） | 有 CDN/自有域名就填 | `https://cdn.example.com` |
| 存储路径 | 对象前缀 | `video-api` |
| 签名有效期（小时） | 没填公开域名时的限时签名时长 | `24` |

- 「公开访问域名」**留空** → 生成**限时签名 URL**（形如 `...?X-Amz-Signature=...`），实测上游能正常抓取。
- 填了 → 直接用固定域名拼链接（更干净，需要桶/CDN 是公开可读的）。
- 阿里云 OSS / Cloudflare R2 / AWS S3 同理，字段几乎一样（R2 额外要 `Account ID`）。

### 方案 C：自定义 / 自建图床（最稳，推荐长期使用）

自己起一个上传接口（有个公网服务器就行），「图床类型」= **自定义**：

| 字段 | 填什么 |
|---|---|
| 上传地址 | 你的接口，如 `https://your-host/upload` |
| 文件字段名 | 接口收文件的字段名，默认 `file` |
| 返回 URL 路径 | 响应里放图片 URL 的路径，如 `data.url`；**留空则自动识别** |
| 鉴权 Header / 前缀 / Token | 需要鉴权时填，如 `Authorization` + `Bearer` + `token` |

最小实现思路：收到 multipart → 存本地目录或对象存储 → 返回 `{"data":{"url":"https://你的域名/xxx.png"}}`。要求只有一条：**返回的 URL 必须能公网匿名访问**。

## 4. 视频渠道怎么选、各渠道必填项

进「**设置 → 视频模型**」→「**默认视频渠道**」，共 8 个选项：

| 渠道 | 适用场景 | 必填 |
|---|---|---|
| **视频 API** | ✅ 推荐。走网关 `api.xiaoyxiao.xyz`，无需额外账号 | Base URL（默认 `https://api.xiaoyxiao.xyz/v1`）、API Key、模型名 |
| UpDream | 有 UpDream 账号 | Access Token **或** Refresh Token |
| Neowow | 有 Neo 账号 | 登录账号（含 Token） |
| 小云雀 | 有 XYQ access key | access key |
| LibTV CLI | 本机装了 LibTV CLI | 画布 UUID |
| ComfyUI | 有 ComfyUI 服务 | 云端地址 + 工作流 JSON |
| 即梦 CLI / 即梦 Agent | 本机 CLI / 浏览器登录态 | Session（Agent 需登录浏览器） |

### 「视频 API」渠道常用模型名（网关已注册，**大小写与短横线都要对**）

```
seedance-2.0-mini-deal     ← 默认，最便宜
seedance-2.0-deal
seedance-2.5-deal
seedance-2.5-pro
doubao-seedance-2.5
dreamina-seedance-2.0 / -fast / -mini
dreamina-seedance-2.5
jimeng-seedance-2.5
minimax-h3-720p / minimax-h3-max
wan3.0-video
```

> 网关按模型名**精确且大小写敏感**匹配渠道。名字写错会返回
> `No available channel for model <name> under group <group>` —— 这是网关报错，不是客户端 bug，换个名字即可。

## 5. 分镜出片流程

1. 打开项目 → 进「**分镜**」页。
2. 确认每个镜头的**参考图**（角色卡 / 首帧衔接图）已绑定。
3. 顶部选择**视频渠道**与**模型**（顶部选择会覆盖「设置」里的默认值）。
4. 点生成 → 「任务」面板看进度与报错。
5. 出片后可在分镜上预览 / 一键导出。

## 6. 报错对照表（查表处理）

| 现象 | 处理 |
|---|---|
| `image_urls / video_urls / audio_urls must be a public http(s) URL` | 去「设置 → 图床」，启用免费图床或自己的图床，点「测试上传」确认可用 |
| `private IP address not allowed` | 参考素材是本机/内网地址，换图床 |
| `UpDream Access Token is not configured` | 填 UpDream Token，或把「默认视频渠道」切回 **视频 API** |
| `No available channel for model <X>` | 模型名不在本站已注册列表里，换成 §4 的名单 |
| `insufficient_user_quota` | 网关余额不足，去充值 |
| `免费图床均不可用：…` | 境外图床被墙/超时，改用云存储或自建图床 |
| 报错里带 `read ECONNRESET` / `请求超时` | 网络抖动；换渠道或稍后重试 |

**看真实原因的日志**：`<数据目录>\data\.logs\video-api.log`
（默认数据目录是与安装目录同级的 `Freedom-Data`，可用 `%APPDATA%\Freedom\gg-storage.json` 里的 `rootPath` 确认）
搜 `submit_shot_failed`，那条记录的 `error` 字段就是上游返回的原文。

## 7. 常见坑

- **单镜设置优先于全局**：某个镜头单独设过渠道（分镜里的单镜设置），即使「设置」里切回「视频 API」，那个镜头仍会按原渠道走。排查时以单镜设置为准。
- **改代码要完全退出 Electron 再启动**：后端是独立子进程，重启才读到改动。
- **图床有效期**：Litterbox 最长 72 小时、Uguu 3 小时。参考图只在提交时被抓取，一般足够；但别把图床链接当长期素材地址用。
- **别把不同渠道的模型名混用**：`sd-720p` / `sd2-c8` 属于别的视频渠道，网关没有这两个名字。
- **渠道连续失败 3 次会熔断 10 分钟**：期间会跳过该渠道，冷却后自动恢复。
