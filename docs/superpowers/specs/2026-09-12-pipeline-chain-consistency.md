# 项目生产链路一致性修复规格

状态：已获用户确认，2026-09-12。

目标：让“剧本 → 元素 → 参考图 → 分镜 → 绑定 → 视频 → 导出”的续跑和重跑链路只消费当前有效数据，并把业务失败准确传递到流水线结果。

范围：

- 剧本生成完成后刷新前端状态，并验证分镜/视频阶段确实产生了可用结果。
- AI 绑定和批量出图在 HTTP 成功但业务失败时，仍按失败处理。
- 章节原文、集切点、分集结果或集剧本变化时，清理当前集的分镜、视频和 pending 任务；历史版本不动。
- 重分集复用集 ID 时，旧媒体不能再次被磁盘对账挂回新集。
- 元素提取的空分类选择表示“全部”，导出只复制每个镜头当前生效的视频版本。

约束：不改变现有 HTTP 路径和供应商接口；保持现有历史视频目录；新增行为必须有可重复的 Node mock 测试。
